# AGENTS.md

All AI agents must read MASTER_PROJECT_PLAN.md first.

Core rules:
- Godot is the official engine.
- ChatGPT 5.5 via OpenCode is the primary model.
- The game is portrait.
- Android and iPhone/iOS are required.
- Required recursive depth is 4.
- Max recursive depth is 4.
- Every node at every depth must use full Spec Kit.
- The game must feel like a real final game, not a prototype or text-square program.
- Use tools proactively when they improve the game.
- Any major decision must compare options by benefit, downside, fit, and recommendation.
- Do not accept claims without artifacts.
- Do not start from scratch after interruption.
