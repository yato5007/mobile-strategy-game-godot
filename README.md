# mobile-strategy-game-godot

## Mobile Progress Dashboard

This project includes a static mobile dashboard at `docs/index.html`.

Update it with:

```bash
./scripts/update_mobile_dashboard.sh
```

To view it from a phone, enable GitHub Pages:

- Settings
- Pages
- Source: Deploy from branch
- Branch: `main`
- Folder: `/docs`

More details: `MOBILE_DASHBOARD.md`.
