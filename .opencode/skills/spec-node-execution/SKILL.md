# Spec Node Execution Skill

Use this skill when executing any Recursive Spec Kit node.

Rules:
- Every node must use full Spec Kit.
- Required depth is 4 and max depth is 4.
- No placeholder depth 4 nodes.
- Each node must produce constitution, spec, clarification, plan, tasks, analysis, checklist, implementation result/instructions, QA, review, integration notes, and NODE_SUMMARY.
- Each node must connect to parent requirements.
