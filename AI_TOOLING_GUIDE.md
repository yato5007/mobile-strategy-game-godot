# AI Tooling Guide

## Mandatory
- Spec Kit
- AGENTS.md
- OpenCode agents
- OpenCode skills
- Progress/checkpoint scripts

## Use when needed
- Context7 for current docs
- Repomix for whole-repo AI review
- MCP servers for specific integrations
- Blender for asset creation
- Godot CLI for export/build automation

## Optional only
- Task Master AI
- BMAD Method
- Kiro
- Cursor Rules
- Claude Project Instructions

## Rule
Tools serve the game. The game does not serve the tools.

Any tool must justify:
- purpose
- priority
- benefit
- downside
- artifact produced
- stop condition
