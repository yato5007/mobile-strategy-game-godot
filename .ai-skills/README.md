# .ai-skills

Reusable skill templates for agents and external AI tools. These are not replacements for OpenCode agents or Spec Kit.

## Rules

- Read `MASTER_PROJECT_PLAN.md` first.
- Do not start from scratch after interruption.
- Do not implement game code before Spec Kit tasks exist.
- Every Spec Kit node must be full and meaningful through required depth 4.

## Skills

- `spec-node-execution.skill.md` — execute one Spec Kit node.
- `spec-node-review.skill.md` — review a node for depth, quality, and non-placeholder content.
- `progress-update.skill.md` — update status/progress/trace files after work.
- `handoff-prep.skill.md` — prepare handoff notes without claiming final completion early.
