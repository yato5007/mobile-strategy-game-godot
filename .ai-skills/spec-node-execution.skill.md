# Skill: Spec Node Execution

Use when executing one `.spec-tree/` node.

## Inputs

- Node path.
- Parent node summary.
- Requirements linked to this node.

## Required Steps

1. Confirm depth does not exceed 4 and does reach required branch depth plan.
2. Write/update `constitution.md`.
3. Write/update `spec.md`.
4. Write/update `clarification.md`.
5. Write/update `plan.md`.
6. Write/update `tasks.md`.
7. Write/update `analysis.md`.
8. Write/update `checklist.md`.
9. Write implementation instructions or result without bypassing tasks.
10. Write QA, review, integration, and documentation notes.
11. Write `NODE_SUMMARY.md`.

## Quality Gates

- No placeholders.
- Options compared for major decisions.
- Acceptance criteria present.
- Integration risks recorded.
- Tests or validation notes present.
