# Skill: Spec Node Review

Use when reviewing a Spec Kit node or subtree.

## Review Checklist

- Full Spec Kit artifacts exist and are non-empty.
- Node has a clear purpose and parent link.
- Decisions include alternatives rejected.
- Required depth 4 is respected.
- No branch is decorative or repetitive.
- Game quality, clarity, win condition, and anti-spreadsheet rules are considered.
- Tests, QA result, review result, and integration notes exist.

## Output

Return `PASS` or `BLOCKED` with the minimal required fixes.
