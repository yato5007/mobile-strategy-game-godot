# DESIGN_SYSTEM.md

This is a bootstrap scaffold. Final design direction must come from Spec Kit.

## Non-Negotiables

- Arabic-first visual and cultural style.
- Portrait-only mobile layout.
- Android and iPhone/iOS safe-area awareness.
- Arabic RTL and English LTR support.
- No hardcoded player-facing UI strings.
- UI must look like a game, not a spreadsheet or admin panel.

## Pending Spec Kit Decisions

- Visual identity and motif.
- Color palette.
- Typography and Arabic font strategy.
- Icon/token/unit style.
- Board/map/arena presentation.
- Motion and feedback rules.
- SFX and audio direction.

## Early Validation Questions

- Is the win condition visible and understandable?
- Does the play area feel like a game space?
- Can Arabic and English layouts both fit portrait screens?
- Do icons, motion, and feedback clarify strategic consequences?
