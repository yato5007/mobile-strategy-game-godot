# CLAUDE_PROJECT_INSTRUCTIONS.md

Read `MASTER_PROJECT_PLAN.md` first. This file is only a derived instruction layer for Claude/Claude Code and must not conflict with the project plan.

## Core Rules

- Godot Engine 4.x is official.
- ChatGPT 5.5 via OpenCode is the primary model in the main workflow.
- Portrait-only mobile game.
- Android and iPhone/iOS support required.
- Required recursive Spec Kit depth: 4.
- Max recursive Spec Kit depth: 4.
- Full Spec Kit for every node at every depth.
- Do not start implementation until Spec Kit tasks exist.
- Do not convert the game into a spreadsheet/text-square prototype.
- Major decisions require option comparison.
- Use artifacts as proof.

## Optional Tooling

- Context7: use for fresh Godot/GDScript/export docs when uncertain.
- Repomix: use for large repo review or handoff, not small edits.
- BMAD: critique layer only, not replacement for Spec Kit.
- Task Master: only after Spec Kit tasks exist.
- Kiro: optional future alternate environment only.
