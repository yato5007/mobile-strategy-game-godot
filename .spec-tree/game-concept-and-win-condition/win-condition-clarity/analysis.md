# Analysis — Win Condition Clarity

## Option Comparison

### Option A — Numeric score only
- Benefit: compact and easy to implement.
- Downside: spreadsheet feel; weak emotional clarity.
- Recommendation: rejected.

### Option B — Pure symbolic progress only
- Benefit: strong game feel.
- Downside: may obscure exact leader state.
- Recommendation: rejected as sole method.

### Option C — Visual Claim with secondary numeric detail
- Benefit: readable and game-like; supports accessibility and precise comparison.
- Downside: requires careful UI/art coordination.
- Recommendation: accepted.

## Accepted Direction
Claim progress should be a visual banner/seal/track metaphor with optional numeric detail for precision.
