# Analysis — Comeback Path Cue

## Option Comparison

### Option A — No comeback cue
- Benefit: cleaner UI.
- Downside: trailing players may feel lost or believe the match is decided too early.
- Recommendation: rejected.

### Option B — Text advice only
- Benefit: easy to understand.
- Downside: can feel like a helper app/tutorial and adds reading burden in portrait.
- Recommendation: rejected as primary method.

### Option C — Automatic comeback boost
- Benefit: keeps matches close.
- Downside: unfair rubber-banding; weakens strategic trust.
- Recommendation: rejected.

### Option D — Public objective-linked visual opportunity thread
- Benefit: preserves fairness, shows actual strategic path, supports game feel.
- Downside: requires objective swing metadata and careful visual design.
- Recommendation: accepted.

## Leaf Conclusion
Use a public, visual, objective-linked comeback cue that communicates opportunity without changing rules.
