# Analysis — Claim Progress Display

## Option Comparison

### Option A — Leaderboard table
- Benefit: direct and simple.
- Downside: spreadsheet feel; weak game identity.
- Recommendation: rejected.

### Option B — Board-only progress without summary
- Benefit: immersive.
- Downside: may be hard to read on portrait mobile.
- Recommendation: rejected as sole display.

### Option C — Banner/Seal visual summary tied to board events
- Benefit: clear, thematic, mobile-friendly, and game-like.
- Downside: requires UX/art discipline.
- Recommendation: accepted.

## Conclusion
Use a visual summary that feels like a ceremonial game object and can be animated later.
