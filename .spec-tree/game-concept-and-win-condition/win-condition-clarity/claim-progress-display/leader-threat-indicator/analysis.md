# Analysis — Leader Threat Indicator

## Option Comparison

### Option A — Plain “1st/2nd/3rd/4th” labels
- Benefit: simple.
- Downside: leaderboard feel; weak indication of whether the lead can change.
- Recommendation: rejected.

### Option B — Alarm whenever leader is ahead
- Benefit: dramatic.
- Downside: noisy and misleading; may create false urgency.
- Recommendation: rejected.

### Option C — Contextual contested-lead state linked to objectives
- Benefit: communicates why the leader is threatened and what matters next.
- Downside: needs objective metadata later.
- Recommendation: accepted.

## Leaf Conclusion
Leader threat should be contextual, visual, and tied to public objectives rather than a static ranking table.
