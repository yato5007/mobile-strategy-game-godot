# Constitution: Team Contribution Display

## Node Identity
- Node: `team-contribution-display`.
- Depth: 4.
- Parent: `team-and-ffa-win-readability`.
- Scope: 2v2 end-match contribution readability.
- Implementation type: future UI leaf tasks only.

## Principles
1. The team result is always primary.
2. Individual contribution must support pride, learning, and cooperation.
3. The UI must not imply that one teammate alone won or lost.
4. The display must be compact enough for portrait mobile.
5. Contribution categories should be positive and understandable.
6. Teammate data must be presented symmetrically.
7. Arabic and English layouts must preserve team-first hierarchy.
8. Empty contribution data must degrade gracefully.

## Required Content
- Team name or color/crest.
- Combined team claim count.
- Each teammate's personal claim count.
- Each teammate's key claim moment, if present.
- One synergy highlight such as “protected final banner” or “opened claim window”.
- Localized labels for all categories.

## Prohibited Content
- Blame labels such as “weak link”.
- Sorting teammates by value in a way that shames the lower contributor.
- Hardcoded English strings.
- Tiny columns that only fit Latin names.
